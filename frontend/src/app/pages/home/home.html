Kepler Objects of Interest · machine learning

From finding planets to deciding which ones to look at first

A gradient-boosted classifier separates real Kepler transit signals from false positives. The new part of this project uses that model to rank 2,248 still-unresolved candidates by how likely they are to be real and how Earth-like they look, so follow-up telescope time can be spent where it matters most.

What this project does

1

Replicate and benchmark

The base paper's MLP is re-run on the same 11 features, then compared with four other model families under repeated cross-validation and a held-out test set with bootstrap intervals.

Results → 2

Go from detection to prioritisation

Every unresolved candidate gets a planet probability and an ESI-inspired Earth Similarity Score. Their product, plus a Pareto front, gives a follow-up shortlist.

Novelty → 3

Ship it as tested software

A Flask API serves the model, this Angular site is the interface, and GitHub Actions test, build and deploy every push to GitHub Pages.

Pipeline →
This is a teaching and research prototype. It works from catalogue values, not raw light curves, and the Earth Similarity Score measures Earth-likeness only, not habitability. Read the limitations.
