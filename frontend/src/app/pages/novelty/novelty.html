Novelty: from detection to prioritisation

The base paper asks a yes/no question: is this signal a planet? This project keeps that question, answers it better, and then asks the question an observer actually faces: which unresolved candidates deserve follow-up first?

How the priority score is defined

pplanet

Probability of CONFIRMED from the deployed LightGBM pipeline. CANDIDATE rows were never used in training.

Earth Similarity Score

sim(x) = 1 − |(x − 1)/(x + 1)| for radius (Earth radii) and insolation (Earth flux); ESS = √(sim(R) · sim(S)).

Priority

priority = pplanet × ESS. Because any weighting is a choice, the Pareto front and a sensitivity check are reported alongside.

ESS is ESI-inspired only. The published Earth Similarity Index (Schulze-Makuch et al., 2011) combines radius, bulk density, escape velocity and surface temperature; it does not use insolation. ESS borrows the same similarity form for the two quantities the Kepler catalogue actually gives. It measures Earth-likeness, not habitability.
