Pipeline

How a change goes from an editor to this website, and how the pieces talk to each other when you run the project on your own computer.

Continuous integration and deployment

.github/workflows/ci.yml

On every push and pull request to main: installs the pinned Python requirements and runs pytest backend/tests, then runs npm ci and npm run build for the Angular app. A red check blocks confidence in the change.

.github/workflows/pages.yml

On every push to main: builds the production bundle with --base-href /<repo-name>/ and deploys dist/frontend/browser to GitHub Pages. Hash routing (#/results) means deep links never hit a missing server route.

System architecture (local run)

1. Start the API

python backend\app.py serves on 127.0.0.1:5000.

2. Start the site

ng serve --proxy-config proxy.conf.json forwards /api to Flask.

3. Classify

Open localhost:4200/#/classifier; blank fields are imputed with training medians.
